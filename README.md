# The Ark Initiative — Website Source

Public website for The Ark Initiative / ARK4 Humanity, a project of Aiding Rejuvenation 4 Kommunities Inc.
Live at https://thearkinitiative.ark4humanity.workers.dev (Cloudflare Worker `thearkinitiative`).

## Layout

- `ark-website/` — the site source that gets deployed
  - `build_site.py` — main generator (pages, library, essays, nav). **Source of truth for most pages.**
  - `build_pillars.py` — generates the 13 pillar pages. **Source of truth for pillar pages.**
  - `deploy-cloudflare.py` — deploys `ark-website/` directly to Cloudflare Workers via API (no wrangler, no CI).
  - `css/`, `js/`, `img/` — static assets (videos excluded from this repo; they live per-pillar on Drive)
  - `library-aeon-wing.html`, `exchange.html`, `restore.html` — standalone hand-built pages (not generated)
- `website-content/essays/` — essay markdown sources wired into the site via the ESSAYS list in `build_site.py`

## Build & deploy

```bash
cd ark-website
python3 build_site.py
python3 build_pillars.py
~/workspace/.venv-deploy/bin/python3 deploy-cloudflare.py   # blake3 lives in that venv
```

Verify after deploy: curl the changed pages, expect HTTP 200. If a new file 404s, deploy once more (known new-file quirk).

## Hard rules (do not break)

- **Never hand-edit `css/style.css`** — it is regenerated by `build_site.py` on every build. Put new styles in the `CSS` variable in `build_site.py`.
- **Never regenerate `guardians.html`** — it is hand-maintained (v2 rebuild lives only in the HTML).
- **Never add `*.mp4` here** — videos are deployed from the live directory and backed up per-pillar on Drive, not in git.
- Dawn's public voice: **no em dashes** — use commas.
- Publishing: Muse holds the Cloudflare deploy credential and publishes. Merge freely; deployment stays with Muse until Dawn says otherwise.
