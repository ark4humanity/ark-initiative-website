THE HEARTH NOOK

All thirteen pillars have a seat here. Sing if you want, leave a story, or pass a note. Nothing in this room is a test, and nobody assigns you a role.

Drafts stay on this device. There is no public story archive and no recording booth behind this page. Saving, hearing a draft, and passing a note use this browser only. Download a text file if you want a copy. Refreshing keeps what this browser stored. Another person's computer cannot see it.

These rooms stay themselves
